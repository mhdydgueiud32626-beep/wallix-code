# WALLIX 4K & Live Video Chrome Extension (Manifest V3)

A high-performance, glassmorphic New Tab replacement built for Google Chrome, Brave, and Microsoft Edge.

## Features
- **60 FPS Video & 4K Static Wallpapers**: Seamless looping video backgrounds and 3840×2160 UHD wallpapers.
- **Frosted Glass Google/AI Search**: Instant web search with optional Gemini AI Mode.
- **Interactive macOS Frosted Dock**: Quick-launch shortcuts with colorful gradient glows.
- **Chrome Storage Integration**: Synchronizes your background, dock shortcuts, and theme settings locally and across devices.

## How to Install in 1 Minute:
1. Click the **"Add to Chrome (1-Click)"** button inside WALLIX, or download the Extension ZIP.
2. Unzip the folder if downloaded as a `.zip`.
3. In Chrome, open `chrome://extensions/`.
4. In the top-right corner, turn ON **Developer mode**.
5. Click **Load unpacked** (top-left) and select this `extension` folder.
6. Open a new tab in Chrome (`Ctrl+T` / `Cmd+T`) — your live wallpaper and dock are ready!
